# Noveris Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild every page of noveris.sk in the approved design system and add the seven new service pages (SK, plus EN drafts).

**Architecture:** The approved prototype in `design-system/gen/*.py` is the markup reference. Its components are ported 1:1 to a JS module `scripts/lib/ui.js` used by the existing zero-dependency generator. Service pages are data (`content/services/<id>.json`) rendered by a section dispatcher. Page chrome (header, drawer, footer) lives in `scripts/lib/layout.js`, and existing templates are rewritten with the new components. Photos are self-hosted through the existing `picture()` pipeline.

**Tech Stack:** Node 22 (built-in `node:test`, no new dependencies), Tailwind 3 (`npm run build:css`), static HTML on GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-11-01-redesign-design.md`

## Global Constraints

  - Slovak copy must be verbatim from `design-system/gen/jana-texty.txt`, or from the current site for pages without new copy.
  - Allowed additions are short eyebrows only, and only the ones the mockups use.
  - No invented facts, superlatives or promises (SAK rules).
- **Contact data:** only the real details: +421 915 622 518 (`tel:+421915622518`), kralusova@noveris.sk, and Turčianska 42, 821 09 Bratislava. Never `905 123 456`, `office@noveris.sk` or `900 123 456` outside form placeholders.
- **No third-party requests in built pages (outside `design-system/`):** no `fonts.googleapis.com`, `fonts.gstatic.com`, `images.unsplash.com` or `images.pexels.com`. The existing `api.web3forms.com` form action and the optional Umami script stay.
- **Visual reference:** markup must match the corresponding `design-system/gen/comp*.py` function. Open the mockup at `http://127.0.0.1:8765/design-system/mockups/<page>.html` to compare.
- **Tokens:** `paper` #fbf9f5, `sand` #f0ece6, `sand-deep` #e7ded1, `chip` #f1ece5, `line` #e6e0d6, `forest` #17302b, `forest-dark` #0f231f, `ink` #1c2420, `body` #4a4740, `muted` #6f6a60, `copper` #8f5535, `copper-light` #e0b08a, `field` #8e867a, `danger` #b3261e. Radii `rounded-card`, `rounded-btn` and `rounded-pill`, and shadow `shadow-soft`. These are already in `tailwind.config.js`.
- **Retired:** `satin-button`, `satin-gradient`, `#735c00`, `#6d5b47` and `dark:` classes must not appear in built pages.
