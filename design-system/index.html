Design system

Warm cream pages, dark forest green for actions and the contact band, copper for eyebrows, icons and links; Newsreader + Manrope; denser spacing than the current site. Everything on this page is rendered with the real compiled Tailwind classes shown beside each component. UI labels in this document are English; sample content is Slovak.
